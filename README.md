# Поиск примитивных элементов мультипликативной группы по модулю

## Общие сведения

Проект представляет собой набор реализаций алгоритмов модульной арифметики и теории чисел на языке Python: тест простоты Миллера-Рабина, генерация больших простых и безопасных простых чисел, быстрый НОД и расширенный алгоритм Евклида, нахождение обратного элемента, бинарное возведение в степень по модулю, метод Гаусса по модулю.

Основная прикладная задача проекта — поиск примитивных элементов (образующих) мультипликативной группы Z/pZ для простого модуля p вида p = 2q + 1 (безопасное простое число). Результат работы сохраняется в файл PRIMITIVES_SET.txt.

## Примитивные элементы: теоретическая база

Пусть p — простое число. Мультипликативная группа Z/pZ имеет порядок p − 1 = 2q и является циклической. Элемент g называется примитивным (образующим), если его порядок равен p − 1, то есть степени g порождают все ненулевые вычеты по модулю p.

Для модуля p = 2q + 1 делители порядка (p − 1) = 2q таковы: 1, 2, q, 2q. Отсюда критерий Эйлера: g является примитивным элементом тогда и только тогда, когда

- g^2 (mod p) != 1;
- g^q (mod p) != 1.

Ключевое свойство, используемое в проекте: если g — примитивный элемент, то любой элемент вида g^k mod p при НОД(k, p − 1) = 1 также является примитивным. Это позволяет строить множество примитивных элементов из одного образующего без проверки порядка каждого кандидата.

## Архитектура

Проект разделен на три уровня.

1. Вычислительное ядро (алгоритмы): miller_rabin_test.py, fast_pow.py, gcd.py, euklid.py, find_inverse.py, gauss.py, primes.py. Модули не зависят от UI и друг от друга, кроме find_inverse -> euklid и find_prime_numbers -> miller_rabin_test/primes.

2. Прикладной слой: primitive_elements.py и find_prime_numbers.py. Комбинируют ядро (тест Миллера-Рабина, НОД, возведение в степень) с криптографическим генератором случайных чисел (secrets, gmpy2.random_state) для решения задачи поиска примитивных элементов.

3. Слой представления: каталог UI. Классы UIprimitives и UImiller_rabin содержат только статические методы печати и записи в файл; бизнес-логика в них отсутствует. Модули ядра вызывают их для отображения прогресса и сохранения результатов.

Точка входа main.py содержит независимые тестовые блоки (test_inverse_element, test_fast_pow, test_miller_rabin, test_find_prime, test_gauss_method, test_get_all_primitive_numbers), демонстрирующие работу каждого модуля. По умолчанию запускается только последний блок.

Внешние зависимости: gmpy2 (арифметика больших чисел, powmod, НОД, ГСЧ), numpy (матричные операции в gauss.py), стандартная библиотека (secrets, math, time).

## Пайплайн getAllPrimitiveNumbers

Функция getAllPrimitiveNumbers(p, g, count) не работает изолированно: она является третьим звеном конвейера, запускаемого из main.py (test_get_all_primitive_numbers(bits)). Полный пайплайн состоит из трех стадий.

### Стадия 1. generateSafePrimeTwist(bits) -> (p, q)

Генерирует пару простых чисел (p, q), где p = 2q + 1.

1. Цикл попыток: q = secrets.randbits(bits) с принудительно установленными старшим и младшим битами (маска bit_mask), что гарантирует bits-битное нечетное число; p = (q << 1) | 1.
2. Предфильтр малыми простыми: вычисляется gmpy2.gcd(q, BIG_PRIME_PRODUCT) и аналогично для p, где BIG_PRIME_PRODUCT — произведение всех простых из FIRST_PRIMES (до 541). Если НОД больше 1, кандидат отбрасывается без дорогих проверок.
3. Быстрая проверка: execMillerRabin с одним свидетелем (k=1) для q и p. Не прошедшие — переход к следующей попытке.
4. Подтверждающая проверка: execMillerRabin с k=15 свидетелями для обоих чисел. Только при двойном успехе пара возвращается.
5. Каждые 5000 попыток обновляется прогресс-бар (UIprimitives.progessBar); по завершении печатается отчет (UIprimitives.SPT) со временем и количеством попыток.

### Стадия 2. getMinPrimitiveNumber(p, q) -> g

Находит наименьший примитивный элемент по модулю p перебором кандидатов g от 2 до 299 (константа SUP). Для каждого кандидата проверяются два условия Эйлера через gmpy2.powmod:

- g^2 mod p != 1 (исключает порядок 1 и 2);
- g^q mod p != 1 (исключает порядок q).

Первый прошедший обе проверки возвращается как базовый образующий g; результат печатается (UIprimitives.MPN). Перебор ограничен малыми значениями, поскольку минимальный примитивный элемент для таких модулей практически всегда мал.

### Стадия 3. getAllPrimitiveNumbers(p, g, count) -> set[int]

Строит множество примитивных элементов на основе свойства степеней образующего.

1. group_order = p − 1. Фактический размер множества: actual_count = min(count, group_order).
2. Если передано g == -1 (признак составного модуля), возвращается пустой список.
3. Цикл до заполнения множества:
   - берется случайная степень k из диапазона [2, p-2] (gmpy2.mpz_random);
   - если НОД(k, group_order) == 1, элемент g^k mod p гарантированно примитивен и добавляется в множество primitives_set (множество автоматически отсекает дубликаты);
   - иначе кандидат отбрасывается.
4. После сбора заданного количества элементов печатается отчет о времени (UIprimitives.APN) и множество записывается в файл PRIMITIVES_SET.txt (UIprimitives.APN_WRITE_FILE), каждый элемент с новой строки.
5. Возвращается множество primitives_set.

Корректность стадии 3 опирается на теорему: для циклической группы порядка n элемент g^k является образующим тогда и только тогда, когда НОД(k, n) = 1. Поэтому каждая найденная степень является примитивным элементом без отдельной проверки порядка; единственная предварительная проверка порядка выполняется один раз на стадии 2.

## Использование

Требуется Python 3.10+ (используются аннотации tuple[int, int], set[int]) и библиотеки gmpy2, numpy.

```
pip install gmpy2 numpy
python main.py
```

В main.py в функции main() раскомментируйте нужный тестовый блок. Пример полного цикла для 2048-битного модуля:

```
test_get_all_primitive_numbers(2048)
```

Параметры: bits — битность безопасного простого p; count — желаемое количество примитивных элементов. Результат дублируется в консоль и в файл PRIMITIVES_SET.txt.

## Замечания по реализации

- Тест Миллера-Рабина вероятностный: True означает "вероятно простое", False — "точно составное". Двухступенчатая схема (k=1 фильтр, k=15 подтверждение) снижает вероятность ложного пропуска при сохранении скорости.
- Все источники случайности основаны на secrets (криптографически стойкий ГСЧ ОС) и gmpy2.random_state, инициализируемого secrets.randbits(128).
- Тяжелые операции (возведение в степень по модулю, НОД больших чисел) делегированы gmpy2; собственные реализации (fastPow, getGCD, execEuklid) присутствуют как учебные и используются в тестовых блоках main.py.
- В getAllPrimitiveNumbers количество различных примитивных элементов по модулю p равно phi(p − 1); при значении count, близком к этому пределу, случайная выборка степеней дает много повторений и цикл замедляется. Параметр count следует задавать существенно меньше phi(p − 1).
- В findPrimeNumbers результат execMillerRabin интерпретируется как булево "is_prime", хотя функция возвращает True для вероятно простых чисел; это осознанное вероятностное допущение.
